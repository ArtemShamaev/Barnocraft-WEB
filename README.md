# Barnocraft WEB

Браузерный форк [Barnocraft Java Edition](https://github.com/ArtemShamaev/Barnocraft-JE). Тот же мир, механики, меню, кубический шрифт, мультиплеер и Python-моды, но вместо Java 17 + jMonkeyEngine — HTML, JavaScript и WebGL 2 (Three.js r149, лежит в `js/lib`). Установка не нужна.

## Руководство игрока

[Как играть: управление, рецепты, печь, кровать, фонари и выживание](docs/player-guide.md).
[Python Mod API v2: SDK, события, вызовы, manifest и примеры модов](docs/PYTHON_MOD_API.md).

## Запуск

**Одиночная игра.** Откройте `index.html` двойным щелчком. Все текстуры и встроенные моды лежат в `js/assets.js`, поэтому страница работает и из файла. Нужен браузер с WebGL 2: Chrome, Edge, Firefox или Safari 15+.

**Через сервер (рекомендуется, обязательно для сети).** Нужен Node.js 18+, npm-пакеты не нужны:

```sh
node server.js          # порт 25565
node server.js 8088     # другой порт
```

Откройте адрес, который напечатает сервер, например `http://localhost:25565/`. Другие компьютеры в локальной сети открывают `http://192.168.1.21:25565/`.

Щёлкните по игре, чтобы захватить мышь. **Esc** отпускает мышь и ставит паузу, как в Java-версии.

### Телефоны и планшеты

Игра работает в мобильном Chrome, Safari (iOS 15+) и Firefox. Лучше играть в горизонтальной ориентации: при входе в мир игра переходит в полноэкранный режим.

| Действие | Касание |
| --- | --- |
| Ходить | Джойстик в левой нижней части экрана: скорость зависит от отклонения |
| Смотреть | Провести пальцем по правой части экрана |
| Прыжок, всплытие, полёт вверх | **↑** |
| Добывать (удерживать), атаковать | **УДАР** |
| Поставить блок, открыть дверь или станок, съесть еду | **ИСП** |
| Полёт вниз в креативе | **↓** |
| Выбрать слот | Коснуться ячейки быстрой панели |
| Пауза, инвентарь, консоль, метки карты | **II**, **E**, **/**, **M** вверху экрана |
| Переложить предмет | Коснуться предмета, затем ячейки; долгое касание берёт один предмет |

Для имени мира, консоли, адреса и кода комнаты открывается экранная клавиатура. На телефоне по умолчанию дальность прорисовки — 2 чанка; её можно увеличить в настройках. Мышь и клавиатура на планшете тоже работают.

## Бесплатный хостинг

- **GitHub Pages** — только одиночная игра (статический сайт без сервера). В репозитории: Settings → Pages → Branch `master`, папка `/ (root)`. Игра откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
- **Render.com** (бесплатный Web Service) — одиночная игра и мультиплеер по интернету. На render.com: New → Blueprint → выберите репозиторий; `render.yaml` уже настроен (`node server.js`). Бесплатный сервер засыпает после 15 минут без посетителей, первое открытие после сна занимает около минуты.

На сайте по https вместо порта используется **код комнаты**. Хозяин открывает мир для сети и называет друзьям код из меню паузы. Друзья открывают тот же сайт, выбирают **Мультиплеер** и вводят этот код. На одном сервере одновременно может быть открыто много миров.

## Мультиплеер в локальной сети

До восьми игроков вместе с хозяином. Браузер не может сам открыть TCP-порт, поэтому `server.js` пересылает сообщения между хозяином и гостями по WebSocket. Мир по-прежнему хранится и просчитывается у хозяина.

1. Хозяин запускает `node server.js`, открывает игру по адресу сервера, входит в мир через **Миры**, нажимает **Esc → Открыть для сети**, выбирает **Саню** или **Ваню** и порт сервера, затем **Открыть мир**.
2. В меню паузы появится адрес для друзей, например `192.168.1.21:25565`.
3. Гость открывает `http://192.168.1.21:25565/`, выбирает **Мультиплеер** и персонажа и нажимает **Подключиться**. Адрес и порт подставляются автоматически. Tab переключает поле, Backspace удаляет символ, Delete очищает поле, Enter подключает.

Синхронизируются блоки, двери, вода, существа, общие сундуки, печи и камнерезы, оба измерения. Инвентарь гостя действует в пределах подключения. Вкладка хозяина продолжает просчёт мира и в фоне. Если подключиться не удаётся, проверьте, что `server.js` запущен, порт совпадает и межсетевой экран пропускает входящий TCP-порт.

## Меню и сохранения

- **Миры** — пять слотов. Пустой слот создаёт новый случайный мир, существующий загружается. **Создать мир** — мир с именем; можно вводить кириллицу. **↓** скачивает мир в файл `.bcw`, **Импорт** загружает такой файл в свободный слот, **×** удаляет мир.
- **Мультиплеер** — подключение к миру друга.
- **Моды** — список модов; нажмите на мод, чтобы включить или выключить его; можно добавить папку с модом или файл `.py`.
- **Настройки** — дальность прорисовки (2–6 чанков), чувствительность мыши, угол обзора, набор текстур. Нажмите на ползунок в нужном месте.

Миры хранятся в IndexedDB браузера. Каждое сохранение одной транзакцией записывает основной мир и оба измерения. Автосохранение срабатывает каждые 30 секунд игры, при паузе и при сворачивании вкладки. Хранилище привязано к адресу: у `file://…/index.html` и `http://localhost:25565/` разные миры, переносите их через **↓**/**Импорт**. Если браузер запрещает хранилище, например в приватном окне, игра предупредит, что миры не сохранятся.

## Мир

Мир такой же, как в Java-версии: 60 × 40 чанков (960 × 640 блоков), высота 128. Есть холмы, горы, каньоны, реки с рыбами, пустыни, леса, пещеры с выходами на поверхность, уголь, железо, золото и глубинная порода. Данные генерируются по запросу регионами 80 × 80. Меши чанков и освещение (небесный и блочный свет) строятся в Web Worker. День, ночь, небо с солнцем, луной, звёздами и облаками, овцы, зомби, рыбы, водяная симуляция, фермерство, печь, камнерез, сундуки, кровати, фонари, двери, ступеньки, поворачиватель, креатив (`gamemode 1`), консоль **F3** и измерение **Адский лес** с порталами, бесами и кабанами работают как в Java-версии.

Генератор шума и случайных чисел переписан на 32-битную арифметику JavaScript. Поэтому один и тот же seed даёт в WEB и Java разные, но статистически одинаковые миры. Файлы сохранений Java (`.dat`) не читаются.

## Python-моды

Моды выполняет [Pyodide](https://pyodide.org) — CPython 3 для WebAssembly — в Web Worker. Pyodide загружается с `cdn.jsdelivr.net` при первом входе в мир с включёнными модами, поэтому для модов нужен интернет. Протокол, SDK (`mods/sdk/barnocraft.py`) и моды те же, что в Java Edition. Встроены «Мини-карта» и «Лучники и волки». Мод в браузере изолирован песочницей и не видит файлы компьютера.

## Исправления относительно Java Edition

Эти недочёты исправлены в WEB. Исправления, отмеченные *(и в Java)*, перенесены и в Java Edition.

- Перенос инструмента по одному (ПКМ) и через сундук больше не восстанавливает прочность; вёдра больше не складываются в стопку *(и в Java)*.
- Предметы из сундука попадают в ту ячейку, куда их перетащили; при переносе в сундук предметы берутся из выбранной ячейки, а не из первой подходящей *(и в Java)*.
- Подобранные предметы и добыча с адских мобов при полном инвентаре остаются на земле, а не исчезают *(и в Java)*.
- Печь плавит и при закрытом окне печи, как обещает руководство *(и в Java)*.
- `setblock`, `tp portal` и исчезающий сундук погибшего сразу перестраивают меш чанка *(и в Java)*.
- Кэш регионов увеличен с 8 до 16: при дальности 5–6 чанков регионы больше не генерируются заново каждый кадр *(и в Java)*.
- Подсветка кнопок при наведении сохраняет их цвет: «Удалить» остаётся красной, «Создать» — зелёной *(и в Java)*.
- Под водой включается синий туман: шейдер его поддерживал, но флаг не выставлялся *(и в Java)*.
- Сообщение о гибели показывается в игре. Если для сундука погибшего нет места, вещи выпадают, а не остаются в инвентаре *(и в Java)*.
- Ползунки настроек показывают текущее значение *(и в Java)*; в WEB значение задаётся щелчком по ползунку.
- Имя мира можно вводить на кириллице *(и в Java)*. Длинные названия миров и модов больше не вылезают за край меню, подпись «Быстрая панель» в сундуке не перекрывает ячейки *(и в Java)*.
- `tp river` ищет реку по рельефу и не генерирует десятки дальних регионов *(и в Java)*.
- Зомби нападают на ближайшего игрока, в том числе на гостя, а не только на хозяина.
- Существа и предметы темнеют ночью и в пещерах: в Java они светились без освещения.
- Перетаскивание в инвентаре работает и двумя щелчками, а под курсором видно, что вы несёте. У предметов есть всплывающие подсказки.
- README исправлен: мир — 60 × 40 чанков высотой 128, полные сутки длятся 10 минут *(и в Java)*.

## Код

- `index.html` — страница; `server.js` — HTTP-сервер и WebSocket-ретранслятор без зависимостей.
- `js/core.js` — блоки, предметы, детерминированный шум и случайность.
- `js/terrain.js` — рельеф, реки, пещеры, руды, деревья, Адский лес, порталы, регионы.
- `js/world.js`, `js/player.js`, `js/inventory.js` — мир, станки, вода, существа, физика игрока, инвентарь и крафт.
- `js/modworld.js`, `js/mods.js` — сущности модов, консоль команд, Python Mod API на Pyodide.
- `js/mesher.js` — меши чанков и освещение (выполняется в Web Worker).
- `js/render.js`, `js/texgen.js`, `js/ui.js` — Three.js-сцена и шейдеры, процедурные текстуры и шрифт, меню и HUD.
- `js/save.js`, `js/net.js`, `js/game.js` — сохранения, мультиплеер, экраны и игровой цикл.
- `assets/textures` — исходные PNG. `tools/build-assets.py` (Python 3 + Pillow) собирает из них и из `mods/` файл `js/assets.js`.
